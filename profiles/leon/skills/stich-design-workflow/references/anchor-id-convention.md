# Sidenav Anchor ID Convention

Each chapter heading in `part1.html` through `part7.html` carries an `id` attribute that the sidenav sub-menu links scroll to.

## Pattern

```
part{page}-{chapter}        → Major chapter headings (h2 sections)
part{page}-{chapter}-{sub}  → Sub-chapter headings (h3/h4 sub-sections)
```
